About GroundTruth

GroundTruth is a free, source-linked reference for 2026 US import duty rates, MPF (Merchandise Processing Fee), HMF (Harbor Maintenance Fee), Section 301/232 surcharges and landed cost estimates, organized by product and country of origin.

Who built this

GroundTruth is published by PixHarvest, a data-API studio for AI agents. PixHarvest maintains five change-intelligence APIs (Shopify stores, GitHub repos, App Store apps, Hacker News mentions, and hiring activity) plus this tariff reference. The tariff dataset is also served as a REST JSON API and MCP tool so agents and importers can pull live rates programmatically.

What this site is for

Importers, freight forwarders, e-commerce sellers and AI agents who need quick, machine-readable duty estimates. Each product page shows the base HTS rate, MPF/HMF, Section 301 & 232 surcharges where applicable, and a landed-cost estimate by origin country.

Data maintenance

Rates are reviewed regularly against official publications (see Data sources). This site reflects the tariff environment as of 2026-10-01. Tariff policy changes frequently; always confirm with a licensed customs broker or the official HTS before filing an entry.
